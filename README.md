# AI for Knowledge Workers Resources

Copy-ready prompts, skills, and workflow resources for practical AI work.

## Start here

1. Choose a category.
2. Open a resource folder.
3. Read its `README.md`.
4. Copy the prompt or skill into a local operating-agent session.
5. Provide your own authorized source files and assets.

## Categories

- [PowerPoint](powerpoint/) — Build and reproduce branded, editable presentations.
- [Spreadsheets](spreadsheets/) — Apply practical AI workflows to spreadsheet work.
- [Documents](documents/) — Create and improve working documents.
- [Diagrams](diagrams/) — Turn structured ideas into useful visuals.
- [Agent workflows](agent-workflows/) — Reusable patterns for local AI agents.

## Featured resource

[Branded Template Skill Builder](powerpoint/branded-template-skill/) turns an approved PowerPoint template and canonical logo into a reusable presentation skill.
