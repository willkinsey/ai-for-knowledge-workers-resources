# Branded Template Skill Builder

Create a reusable presentation skill from an approved `.pptx` template and canonical logo using a local, file-capable operating agent such as Codex or Claude Code.

## How to use

1. Start a local operating-agent session.
2. Attach the approved PowerPoint template and canonical logo. If the logo is missing, ask the agent to request it before proceeding.
3. Copy the contents of [PROMPT.md](PROMPT.md) into the session.
4. Review the generated skill, its references, and a test deck before using it for real work.
5. Use only source materials you are authorized to use.

The prompt documents a brand system; it does not grant permission to reuse the deck, logo, imagery, or other visual assets. See the repository's [content-rights guidance](../../CONTENT-RIGHTS.md).
