# Diagram Design Companion

A meta-prompting companion that turns an idea into a clear, approved brief for the Diagram Design plugin.

## What It Does

- Accepts anything from a short idea to detailed notes or a transcript.
- Asks only questions that could change the diagram.
- Recommends a useful diagram type and organizes the content.
- Hands a compact brief to Diagram Design instead of crowding the finished visual with planning notes.

## What You Need

- Codex with local skill support.
- The Diagram Design plugin installed and available.
- Your own authorized source material and visual assets.

This companion does not include, copy, or modify the Diagram Design plugin.

## Install and Use

1. Copy this folder into your local Codex skills folder as `diagram-design-companion`.
2. Restart Codex if the skill does not appear.
3. Start with: `Use $diagram-design-companion to help me create a diagram from this idea: ...`

The skill can also activate automatically when you want to make a diagram but its message or structure still needs to be worked out.

## Important Limits

The brief does not approve business facts, publication, private-data use, or rights to third-party logos and visual assets. Review the content and the rendered diagram before sharing it.
